# Osaka Collector
Do you want to collect Osakas appearing all over the window? You can now with this free-to-use Osaka Collector!

This is a minigame where you control a Osaka player, your goal is to collect as many Osaka targets you can, by avoiding Osaka hazards that appear along with your progress.

# Proper file setting:

Dump all files into a single folder (e.g. Osaka), then decompress `Osaka.rar` in the folder along with the files, then execute it!

# How to play:

Use the `arrow keys` or `WASD` to move as Osaka player

Use `Shift` key to use boost

Touch the Osaka targets while avoiding Osaka hazards

# Difficulties:

Osaka Collector adds difficulty by player speed and hazard rate.

Normal mode (default) stands by `PlayerSpeed = Normal` and `HazardRate = Normal (Every 3)`.

However, full hard mode stands by `PlayerSpeed = Fast` and `HazardRate = Hard (Every 2)`.

You can change this in the Settings menu.

# Fun Fact

Since the script only searches for file names, you can change the audio or image files (as long as they match the names)
